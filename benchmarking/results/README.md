# Results

Keep curated benchmark summaries here when they are worth committing.

Everything in this directory is a **point-in-time observation with no
performance claim attached** (manual evidence lab — see
`benchmarking/README.md` "Measurement class"). Nothing here is
baseline- or gate-eligible: no seed, no repeats, no `cv_pct`, not ratcheted.

Use this directory for:

- point-in-time score snapshots (never keep-gate baselines)
- comparison tables
- charts we want to preserve in git

Raw run logs and scratch outputs should go under `benchmarking/runs/`, which stays ignored.
